# Как запустить агента?
## Зайти в окружение и проверить его
Зайти в папку myAgent и проверить наличие chainlit с помощью "chainlit --version", установить при необходимости (chainlit несовместим с python 3.14!!!, работайте с 3.13 и ниже)
Зайти в окружение с помощью ".venv\Scripts\activate" (в начале командной строки появится (venv) )
Убедится в наличии библиотек с помощью "pip install pydantic-ai requests openai". Так мы убедимся что библиотеки присутствуют, если они уже есть, то они обновятся.
## Проверить доступность модели Qwen
Подключится к сети и проверить доступность LLM с помощью "ping 10.45.0.75"
## Запуск
Запустить агента с помощью "./start-agent.ps1" через консоль
