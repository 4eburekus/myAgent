# Как запустить агента?
## Зайти в папку агента myAgent
Зайти в папку myAgent с помощью "cd myAgent"
## Проверить доступность модели Qwen
Подключится к сети и проверить доступность LLM с помощью "ping 10.45.0.75"
## Запуск
Собрать агента с помощью "docker-compose up -d"
Впоследствие запускать с помощью "docker-compose up --build -d"
